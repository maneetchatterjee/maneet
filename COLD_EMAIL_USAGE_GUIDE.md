## 🎓 Technical Concepts Explained

### Control Barrier Functions (CBFs)
Mathematical tools that ensure safety constraints are never violated in control systems.

### Neural Certificates
Neural networks used to approximate Lyapunov functions or barrier functions for stability/safety verification.

### Bootstrapping Problem
The circular dependency in safe learning: you need to know what's safe to learn safely, but you need to learn to know what's safe.

### Model Predictive Control (MPC)
Optimization-based control method that computes control actions by solving an optimization problem at each time step.

### Time-varying CBFs
Barrier functions that adapt over time as the system or environment changes.

### Partial Observability
Situations where the robot cannot fully observe the state of the system or environment.
